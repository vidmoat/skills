# Real Estate Editor: sources and evidence (researched October 2026)

- Zillow Showcase: at most 120s, one video, autoplays muted: https://grow.zillow.com/lo/showcase-getting-started-guide/editing-listings
- Walking order, screen direction, shot lengths, vertical cut: https://runway.com/resources/real-estate-walkthrough-video ; https://async.com/blog/how-to-make-a-real-estate-video/
- Shot length and drop-off at 6s (vendor): https://imagen-ai.com/post/real-estate-video-editing/ ; stricter under-3s benchmark: https://shortgenius.com/blog/real-estate-video-editing
- Unbranded MLS tours (rules vary by MLS): https://blog.kuula.co/mls ; https://support.mlsnow.com/hc/en-us/articles/6938718774043-Add-a-Virtual-Tour-to-a-Listing ; NorthstarMLS upload limits: https://northstarmls.com/resources/using-the-add-edit-video-suite/
- Fair housing advertising guidance: https://fairhousinginstitute.com/fair-housing-advertising-guidelines/ ; "primary" vs "master": https://www.boston.com/real-estate/fall-house-hunt/2021/09/14/realty-agents-using-more-inclusive-terms/
- California AB 723 (altered listing images, in force 1 Jan 2026; the text addresses images): https://beverlyhillscourier.com/2025/11/23/californias-new-disclosure-rule-for-digitally-altered-real-estate-marketing/
- Window pull technique: https://fotober.com/master-the-window-pull-technique-for-gorgeous-real-estate-photo

Folklore: "listings with video get 403% more inquiries" has no original study; never repeat it. No official Zillow or Realtor.com file spec was found; 1080p and under 200 MB is vendor guidance.
