# Human editing scopes

Read this when the user asks for a human editor.

Use `quote_expert_edit` with their complete brief (15 to 4,000 characters) and an optional owned `projectId`. Ask for footage duration, final duration or output count and the desired changes. Return clarification questions as questions; never hide them or claim a booking. The tool only prepares an estimate. Send the `reviewUrl` so the user can review the scope and choose paid work or the optional volunteer queue. Never describe volunteers as guaranteed free labour; volunteering does not affect paid-job access. Extra AI generation and licensed assets need separate agreement. Never promise automatic editor payouts.
