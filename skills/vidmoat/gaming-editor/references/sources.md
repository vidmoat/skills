# Gaming Editor: sources and evidence (researched October 2026)

Primary:
- YouTube Shorts up to 3 minutes, and a Short over 1 minute with an active Content ID claim is blocked worldwide: https://support.google.com/youtube/answer/15424877
- YouTube fair use (no "magic words"): https://support.google.com/youtube/answer/9783148
- Twitch clips API (clips 5 to 60s): https://dev.twitch.tv/docs/api/clips/ ; Twitch music rules: https://legal.twitch.com/legal/music/

Practice and vendor guidance (starting values):
- Chat spike detection in 10s windows and starting the clip about 30s early: https://www.opus.pro/blog/twitch-vod-to-clips-api
- Payoff-first vertical openers, vertical stacks: https://insights.gg/blog/how-to-post-gaming-clips-to-tiktok
- Silence-cut defaults (-30 dB, 0.5s): https://www.opus.pro/blog/auto-jump-cut-editors
- Voice vs game levels (sources differ by 5 to 10 dB): https://obsproject.com/forum/threads/volume-levels-meter.140357/ , https://voxbooster.com/blog/mix-voice-with-background-music
- Meme sound overuse ("I paid someone from Fiverr"): https://knowyourmeme.com/memes/fiverr-editors-i-paid-someone-from-fiverr
- Short length is contested (creators under 30s, view data favours 50 to 60s): https://www.adobe.com/express/learn/blog/youtube-shorts-length-study , https://piktochart.com/blog/how-long-youtube-shorts/

No first-hand editor accounts were found for the named streamers; facecam layout ratios are convention, not evidence.
